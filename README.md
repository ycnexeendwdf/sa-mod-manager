## Overview

SA Mod Manager is the purpose-built mod manager for the Steam releases of Sonic Adventure DX and Sonic Adventure 2, handling mod installation from an integrated browser, load-order management with conflict detection, gameplay and bugfix code patches, and save file backup. It is the standard tool used by the Sonic Adventure modding community for both casual play and competitive speedrunning configurations.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **SA Mod Manager** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Integrated Mod Browser** | Download and install community mods from the integrated catalog |
| **Load Order Control** | Drag-and-drop mod priority with visual conflict indicators |
| **Code Patches** | Apply gameplay fixes and enhancement patches alongside content mods |
| **Save Management** | Backup and restore save files before testing major mod configurations |
